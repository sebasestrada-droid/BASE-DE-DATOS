# BASE-DE-DATOS
Aplicando Funciones de Agrupación – SQL Oracle

Descripción del proyecto

Este proyecto corresponde a la actividad sumativa de la asignatura de Base de Datos de Duoc UC, cuyo objetivo es aplicar sentencias SQL y funciones de agrupación para obtener información relevante desde una base de datos relacional.

El desarrollo utiliza Oracle SQL y SQL Developer, trabajando con el modelo de datos de la empresa ficticia ASOCIADOS, dedicada a la administración y arriendo de propiedades.

Objetivos

- Aplicar funciones de agrupación y funciones SQL de una fila.
- Utilizar las cláusulas "GROUP BY", "HAVING", "WHERE" y "ORDER BY".
- Implementar condiciones mediante "CASE".
- Realizar cálculos numéricos y operaciones con fechas.
- Utilizar variables de sustitución para consultas parametrizadas.
- Presentar resultados ordenados y con formatos adecuados.

Casos desarrollados

Caso 1: Análisis de propiedades

Genera un informe comercial agrupado por tipo de propiedad, mostrando:

- Cantidad de propiedades.
- Valor máximo y mínimo de arriendo.
- Promedio de arriendo.
- Clasificación ESTÁNDAR o PREMIUM.
- Total de gastos comunes.

Caso 2: Análisis de antigüedad de empleados

Genera un informe de empleados de la categoría Ejecutivo de Arriendo, considerando su antigüedad y sucursal.

Incluye:

- Clasificación salarial ALTO o MEDIO.
- Cálculo de años de servicio.
- Determinación del bono de antigüedad del 5%, 10% o 15%.
- Ordenamiento por sueldo de mayor a menor.

Caso 3: Lista de clientes

Clasifica a los clientes según su renta:

- PREMIUM.
- ALTA.
- MEDIA.
- BAJA.

Además, calcula la cantidad de clientes por clasificación, la renta promedio y el estado de disponibilidad de teléfono.

Tecnologías utilizadas

- Oracle Database.
- Oracle SQL Developer.
- Lenguaje SQL.

Ejecución

1. Conectarse a Oracle Database utilizando el usuario correspondiente.
2. Ejecutar el script oficial de creación y poblamiento de tablas.
3. Abrir el archivo "Actividad_SQL_Aplicando_Funciones_Agrupacion.sql".
4. Ejecutar el script desde SQL Developer.
5. Ingresar los valores solicitados por las variables de sustitución.
